# ПРИМЕР. Скопируйте в sshd4a-targets.txt (рядом со скриптом) и заполните. Свой файл при обновлении не затирается.
# Sshd4a extented: адреса для перебора (sshd4a-ctl.bat).
# Формат:  имя = хост[:порт]     Если порт не указан, берётся порт SSH с телефона.
# Адреса самого телефона (Wi-Fi, ZeroTier и т. п.) скрипт добавляет автоматически через adb;
# здесь нужны те адреса, которые телефон про себя не знает, например FRP на VDS.
#
# frp       = vds.example.com:6000
# zerotier  = 10.147.17.55
# lan       = 192.168.1.50
#
# Служебные строки для adb (необязательно):
# какой adb.exe использовать (например, тот же, что у программы AYA):
# adb-path    = C:\Tools\platform-tools\adb.exe
# подключиться к телефону по Wi-Fi перед работой:
# adb-connect = 192.168.1.50:5555
